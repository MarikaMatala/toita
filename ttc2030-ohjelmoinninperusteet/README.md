# Ohjelmoinnin perusteet

## 🇫🇮 Suomeksi

Tässä kansiossa on ohjelmoinnin perusteisiin liittyviä opintojen aikana tehtyjä harjoituksia, tehtäviä ja esimerkkejä.

Harjoituksissa on perehdytty ohjelmoinnin peruskäsitteisiin, ohjelmointilogiikkaan, tietorakenteisiin sekä ongelmien ratkaisemiseen ohjelmallisesti. Tehtävissä on harjoiteltu koodin kirjoittamista, ohjelmien rakennetta ja erilaisten ohjelmointitehtävien ratkaisemista.

Kansio toimii työnäytteenä ohjelmoinnin perustaidostani ja siitä, miten olen soveltanut ohjelmoinnin periaatteita käytännön tehtävissä.

### Osaamista

- Ohjelmoinnin perusteet
- Ohjelmointilogiikka
- Muuttujat ja tietotyypit
- Ehtolauseet ja silmukat
- Funktiot ja metodit
- Tietorakenteet
- Ongelmanratkaisu
- Koodin kirjoittaminen ja kehittäminen
- Git ja versionhallinta
