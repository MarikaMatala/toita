# PowerShell & Shell

## 🇫🇮 Suomeksi

Tässä kansiossa on PowerShell- ja shell-komentoihin liittyviä harjoituksia, tehtäviä ja työnäytteitä. Materiaalit ovat opintojen ja käytännön harjoittelun yhteydessä tehtyjä töitä.

Harjoituksissa on perehdytty komentorivin käyttöön, skriptaukseen, tiedostojen ja hakemistojen käsittelyyn sekä erilaisiin järjestelmänhallintaan liittyviin tehtäviin.

Kansio toimii työnäytteenä komentorivi- ja skriptausosaamisesta sekä siitä, että olen käyttänyt kehitysympäristöjen lisäksi myös komentorivityökaluja osana ohjelmistokehityksen opintoja.

### Osaamista

- PowerShell
- Shell / komentorivi
- Skriptaus
- Tiedostojen ja hakemistojen käsittely
- Komentojen ja komentorivityökalujen käyttö
- Ohjelmistokehityksen työkalut ja ympäristöt
