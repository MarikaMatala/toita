# TTC2060 – Scripting and Automation

## 🇫🇮 Suomeksi

Tässä kansiossa on JAMKin TTC2060 – Skriptaamisen ja automatisoinnin perusteet -kurssilla tehtyjä harjoituksia ja tehtäviä.

Kurssilla perehdyttiin komentorivin käyttöön, skriptaukseen ja tehtävien automatisointiin sekä Windows- että Linux-ympäristöissä. Harjoituksissa käytettiin PowerShelliä ja Bash/Shell-skriptausta.

Tehtävissä harjoiteltiin muun muassa muuttujien ja ehtolauseiden käyttöä, silmukoita, funktioita, komentorivityökaluja, tiedostojen ja prosessien käsittelyä sekä skriptien suorittamista ja automatisointia. Kurssin sisältöihin kuului myös PowerShellin käyttö järjestelmänhallintaan liittyvissä tehtävissä sekä SSH:n hyödyntäminen etäyhteyksissä. :contentReference[oaicite:1]{index=1}

## 🇬🇧 English

This folder contains exercises and assignments completed during JAMK's TTC2060 – Basics of Scripting and Automatization course.

The course covered command-line usage, scripting and task automation in both Windows and Linux environments. The exercises included PowerShell and Bash/Shell scripting.

The assignments provided practical experience with variables, conditional statements, loops, functions, command-line tools, file and process management, as well as executing and automating scripts. The course also covered PowerShell for system administration tasks and using SSH for remote access and command execution. :contentReference[oaicite:2]{index=2}
