# WUIP Exercises

## 🇫🇮 Suomeksi

Tässä kansiossa on JAMKin web-käyttöliittymiin ja web-ohjelmointiin liittyviä harjoituksia ja tehtäviä.

Harjoituksissa on perehdytty web-käyttöliittymien toteuttamiseen, JavaScript-ohjelmointiin sekä selaimessa toimivien interaktiivisten web-sovellusten kehittämiseen. Tehtävissä on harjoiteltu muun muassa käyttöliittymän toiminnallisuuksien toteuttamista, ohjelmointilogiikkaa ja web-sivun rakenteen käsittelyä.

Kansio toimii työnäytteenä web-kehityksen ja frontend-ohjelmoinnin osaamisestani.
