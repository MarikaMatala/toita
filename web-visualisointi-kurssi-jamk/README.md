# Web-visualisointi – JAMK

## 🇫🇮 Suomeksi

Tässä kansiossa on JAMKin Web-visualisointi-opintojaksolla tehtyjä harjoituksia ja tehtäviä.

Opintojaksolla perehdyttiin web-ympäristössä tapahtuvaan visuaaliseen esittämiseen ja web-sisältöjen toteuttamiseen. Harjoituksissa yhdistyvät web-kehitys, ohjelmointi, datan visuaalinen esittäminen ja käyttöliittymien suunnittelu.

Web-visualisointi on osa JAMKin tieto- ja viestintätekniikan sovelluskehityksen ja digitaalisen median opintoja. Opintojakso on laajuudeltaan 5 opintopistettä. :contentReference[oaicite:1]{index=1}

Kansio toimii työnäytteenä web-kehityksen, frontend-toteutuksen ja visuaalisen esittämisen osaamisestani.

### Osaamista

- Web-kehitys
- Frontend-kehitys
- Web-visualisointi
- Datan visuaalinen esittäminen
- Käyttöliittymien toteuttaminen
- Visuaalinen suunnittelu
- Ohjelmointi
- Web-teknologiat

## 🇬🇧 English

This folder contains exercises and assignments completed during JAMK's Web Visualisation course.

The course focused on visual presentation in web environments and creating web-based content. The exercises combine web development, programming, data visualisation and user interface design.

Web Visualisation is part of JAMK's Information and Communications Technology studies within the application development and digital media areas. The course is worth 5 ECTS credits. :contentReference[oaicite:2]{index=2}

This folder serves as a work sample demonstrating my skills in web development, frontend implementation and visual presentation.
