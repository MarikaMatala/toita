# Olio-ohjelmointi

## 🇫🇮 Suomeksi

Tässä kansiossa on olio-ohjelmointiin liittyviä opintojen aikana tehtyjä harjoituksia, tehtäviä ja työnäytteitä.

Harjoituksissa on perehdytty olio-ohjelmoinnin keskeisiin periaatteisiin, kuten luokkiin, olioihin, metodeihin, ominaisuuksiin ja ohjelman rakenteen suunnitteluun. Tehtävissä on harjoiteltu ohjelmointilogiikan toteuttamista sekä koodin jäsentämistä selkeisiin ja uudelleenkäytettäviin kokonaisuuksiin.

Kansio toimii työnäytteenä ohjelmointiosaamisestani ja olio-ohjelmoinnin perusteiden hallinnasta.

### Osaamista

- Olio-ohjelmointi
- Ohjelmointilogiikka
- Luokat ja oliot
- Metodit ja ominaisuudet
- Koodin rakenne ja uudelleenkäytettävyys
- Ohjelmistokehityksen perusteet
- Git ja versionhallinta
