# TTC8440 – Object-oriented Programming

## 🇫🇮 Suomeksi

Tässä kansiossa on JAMKin TTC8440 – Olio-ohjelmointi -kurssilla tehtyjä harjoituksia ja tehtäviä.

Kurssilla perehdyttiin olio-ohjelmoinnin keskeisiin periaatteisiin ja niiden soveltamiseen käytännön ohjelmointitehtävissä. Harjoituksissa toteutettiin ohjelmia, joissa hyödynnettiin luokkia, olioita, metodeja ja muita olio-ohjelmoinnin rakenteita.

Tehtävissä harjoiteltiin myös ohjelmien rakenteen suunnittelua, koodin uudelleenkäytettävyyttä sekä ongelmien ratkaisemista olio-ohjelmoinnin avulla.

## 🇬🇧 English

This folder contains exercises and assignments completed during JAMK's TTC8440 – Object-oriented Programming course.

The course focused on the core principles of object-oriented programming and their practical application in programming tasks. The exercises involved developing programs using classes, objects, methods and other object-oriented programming concepts.

The assignments also provided practical experience in program structure, code reusability and solving programming problems using object-oriented approaches.
