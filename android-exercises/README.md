# Android Exercises

## 🇫🇮 Suomeksi

Tässä kansiossa on Android-sovelluskehitykseen liittyviä opintojen aikana tehtyjä harjoituksia, tehtäviä ja työnäytteitä.

Harjoituksissa on perehdytty Android-sovellusten kehittämiseen, käyttöliittymien toteuttamiseen sekä mobiilisovellusten ohjelmointiin. Materiaalit ovat osa sovelluskehityksen opintojani ja osoittavat käytännön kokemusta Android-kehityksestä.

Kansio toimii työnäytteenä mobiilisovellusten ja sovelluskehityksen osaamisestani.

### Osaamista

- Android-sovelluskehitys
- Kotlin
- Android Studio
- Mobiilisovellusten käyttöliittymät
- Sovelluslogiikan toteuttaminen
- Ohjelmointi
- Git ja versionhallinta
