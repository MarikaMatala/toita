# TTC8430 – Web Server Programming with an Application Framework

## 🇫🇮 Suomeksi

Tässä kansiossa on JAMKin TTC8430 – Web-palvelinohjelmointi sovelluskehyksellä -kurssilla tehtyjä harjoituksia ja tehtäviä.

Kurssilla perehdyttiin web-palvelinsovellusten kehittämiseen sovelluskehyksen avulla sekä frontendin ja backendin väliseen kommunikointiin. Harjoituksissa toteutettiin palvelinpuolen toiminnallisuuksia, REST-rajapintoja ja tietokantayhteyksiä.

Kurssilla käsiteltiin muun muassa CRUD-toiminnallisuuksia, MongoDB-tietokantaa, API-rajapintojen testaamista sekä web-sovellusten rakennetta ja tietoturvaan liittyviä käytäntöjä. JAMKin kurssin tavoitteisiin kuuluu web-sovellusten suunnittelu ja toteuttaminen siten, että käyttöliittymä kommunikoi palvelinpuolen kanssa ja sovellus hyödyntää tietokantaa. :contentReference[oaicite:2]{index=2}

## 🇬🇧 English

This folder contains exercises and assignments completed during JAMK's TTC8430 – Web Server Programming with an Application Framework course.

The course focused on developing web server applications using an application framework and communication between the frontend and backend. The exercises included implementing server-side functionality, REST APIs and database connections.

The course covered topics such as CRUD functionality, MongoDB databases, API testing, web application architecture and security-related practices. The course objectives included designing and implementing web applications where the user interface communicates with the server side and the application uses a database. :contentReference[oaicite:3]{index=3}
