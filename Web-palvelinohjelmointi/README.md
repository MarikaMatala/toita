# Web-palvelinohjelmointi

## 🇫🇮 Suomeksi

Tässä kansiossa on web-palvelinohjelmointiin liittyviä opintojen aikana tehtyjä harjoituksia, tehtäviä ja työnäytteitä.

Materiaalit liittyvät web-sovellusten toteuttamiseen sekä palvelinpuolen ohjelmointiin ja web-palveluiden toimintaan. Tehtävissä on harjoiteltu web-kehityksen eri osa-alueita ja ohjelmistokehityksen käytäntöjä.

Kansio toimii työnäytteenä web-ohjelmoinnin ja sovelluskehityksen osaamisestani.

### Osaamista

- Web-palvelinohjelmointi
- Web-sovellusten kehittäminen
- Palvelinpuolen ohjelmointi
- API:t ja web-palvelut
- HTTP ja client-server-arkkitehtuuri
- JavaScript
- Ohjelmistokehityksen perusteet
- Git ja versionhallinta
