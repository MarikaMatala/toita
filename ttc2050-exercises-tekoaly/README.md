# TTC2050 – Tekoäly ja data-analytiikka

## 🇫🇮 Suomeksi

Tässä kansiossa on JAMKin TTC2050-kurssilla tehtyjä tekoälyyn ja data-analytiikkaan liittyviä harjoituksia ja tehtäviä.

Kurssilla perehdyttiin Python-ohjelmointiin, datan käsittelyyn ja visualisointiin sekä tekoälyn ja koneoppimisen perusteisiin. Harjoituksissa käytettiin JupyterLab-ympäristöä ja Pythonin kirjastoja datan käsittelyyn, analysointiin ja visualisointiin.

Harjoituksissa käsiteltiin muun muassa koneoppimisen menetelmiä, kuten K-Means-klusterointia ja K-Nearest Neighbors (KNN) -luokittelua. :contentReference[oaicite:1]{index=1}

The exercises included machine learning methods such as K-Means clustering and K-Nearest Neighbors (KNN) classification. :contentReference[oaicite:2]{index=2}
