# Mobile Application Exercises

## 🇫🇮 Suomeksi

Tässä kansiossa on mobiilisovelluskehitykseen liittyviä opintojen aikana tehtyjä harjoituksia, tehtäviä ja työnäytteitä.

Harjoituksissa on perehdytty mobiilisovellusten suunnitteluun, käyttöliittymien toteuttamiseen ja sovelluslogiikan ohjelmointiin. Tehtävissä on harjoiteltu mobiilikehityksen periaatteita sekä erilaisten sovellustoiminnallisuuksien toteuttamista.

Kansio toimii työnäytteenä mobiilisovelluskehityksen ja ohjelmoinnin osaamisestani.

### Osaamista

- Mobiilisovelluskehitys
- Sovelluskehitys
- Käyttöliittymien toteuttaminen
- Sovelluslogiikka
- Ohjelmointi
- Mobiilikäyttöliittymien suunnittelu
- Git ja versionhallinta
