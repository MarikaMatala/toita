# TTC2050 – Data Analytics

## 🇫🇮 Suomeksi

Tässä kansiossa on JAMKin TTC2050-kurssilla tehtyjä data-analytiikkaan liittyviä harjoituksia ja tehtäviä.

Kurssilla perehdyttiin datan käsittelyyn, analysointiin ja visualisointiin sekä data-analytiikan ja koneoppimisen perusteisiin. Harjoituksissa hyödynnettiin Python-ohjelmointia ja Jupyter Notebook -ympäristöä sekä Pythonin kirjastoja datan käsittelyyn ja analysointiin.

Harjoituksissa harjoiteltiin datan tutkimista, muokkaamista ja visualisointia sekä data-analytiikan menetelmien soveltamista käytännön tehtäviin. JAMKin kurssisisällöissä data-analytiikan ja koneoppimisen yhteydessä mainitaan keskeisinä työkaluina esimerkiksi Pandas ja scikit-learn. :contentReference[oaicite:1]{index=1}

## 🇬🇧 English

This folder contains data analytics exercises and assignments completed during JAMK's TTC2050 course.

The course covered data processing, analysis and visualisation, as well as the fundamentals of data analytics and machine learning. The exercises used Python programming and the Jupyter Notebook environment together with Python libraries for data processing and analysis.

The exercises provided practical experience in exploring, processing and visualising data, as well as applying data analytics methods to practical tasks. JAMK's course content identifies tools such as Pandas and scikit-learn as part of the data analytics and machine learning studies. :contentReference[oaicite:2]{index=2}
