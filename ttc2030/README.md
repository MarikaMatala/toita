# Ohjelmointi

## 🇫🇮 Suomeksi

Tässä kansiossa on ohjelmointiin liittyviä opintojen aikana tehtyjä harjoituksia, tehtäviä ja työnäytteitä.

Materiaalit sisältävät erilaisia ohjelmointitehtäviä, joissa on harjoiteltu ohjelmoinnin periaatteita, ohjelmointilogiikkaa sekä ongelmien ratkaisemista koodin avulla.

Kansio toimii työnäytteenä ohjelmointiosaamisestani ja osana tieto- ja viestintätekniikan opintojeni aikana tekemääni projektikokonaisuutta.

### Osaamista
